## 📦 Installation Instructions

1. **Upload Theme**

    ```bash
    Upload WP_Theme folder to: wp-content/themes/
    Rename to: amorfs-blog
    ```

2. **Activate**

    - Go to WordPress Admin > Appearance > Themes
    - Activate "Amorf's Blog Theme"

3. **Configure**

    - Create menus (4 locations)
    - Create required pages
    - Add categories
    - Mark a post as featured
    - Add blog posts with images

4. **Customize**
    - Upload custom logo (optional)
    - Set site identity
    - Configure homepage
    - Adjust colors (optional)
