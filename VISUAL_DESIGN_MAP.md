## 🎨 Color Usage Map

### Blue (#2563EB) Used For:

-   Contact button background
-   Logo gear icon
-   Blog badge text
-   Active navigation links
-   Category active border
-   Hover text colors
-   Active pagination background
-   Newsletter register button
-   Link colors

### Dark Blue (#1E3A8A) Used For:

-   Footer background

### Very Light Blue (#DBEAFE) Used For:

-   Blog badge background
-   Category badge backgrounds (header)

### Dark Gray (#1F2937) Used For:

-   Headings
-   Brand text
-   Card titles
-   Important text

### Medium Gray (#4B5563) Used For:

-   Body text
-   Navigation links
-   Regular content

### Light Gray (#6B7280) Used For:

-   Meta information
-   Excerpts
-   Secondary text

### Muted Gray (#9CA3AF) Used For:

-   Date/time stamps
-   Very subtle text

### Light Backgrounds:

-   White (#FFFFFF) - Cards, main bg
-   Light Gray (#F9FAFB) - Category sidebar
-   Subtle Gray (#F3F4F6) - Hover states

## 🎯 Interactive Elements

### Clickable Areas:

1. Logo (→ Home)
2. Navigation items (→ Pages)
3. Contact button (→ Contact page)
4. Featured post (→ Single post)
5. Recent post cards (→ Single posts)
6. Category items (→ Category archives)
7. Blog cards (→ Single posts)
8. Pagination numbers (→ Page navigation)
9. Footer links (→ Various pages)
10. Newsletter submit (→ Form submission)

### Hover Effects:

-   All cards lift with shadow
-   Buttons darken
-   Links change color
-   Images scale slightly
-   Transforms are smooth (0.3s)
