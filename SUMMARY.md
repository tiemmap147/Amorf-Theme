## 💡 Tips Sử Dụng

### Để tùy chỉnh giao diện:

1. **Đừng sửa file gốc** → Dùng `css/custom.css`
2. **Chỉnh template parts** → Dễ maintain hơn
3. **Dùng child theme** → Cho customization phức tạp
4. **Test changes** → Trên local trước khi deploy

### Để mở rộng theme:

1. **Thêm hàm mới** → Vào `functions.php`
2. **Tạo template mới** → Vào `page-templates/`
3. **Thêm widget area** → Trong `functions.php`
4. **Hook vào actions** → Dùng `add_action()` và `add_filter()`

### Để debug:

1. **Enable WP_DEBUG** → Trong wp-config.php
2. **Check linter** → Trong code editor
3. **Use var_dump()** → Để xem dữ liệu
4. **Check browser console** → Cho JavaScript errors
