# Theme Screenshot Guide

## Required Screenshot

For the theme to display properly in WordPress admin, you need to create a screenshot.

### Screenshot Specifications

-   **Filename**: `screenshot.png` (or `screenshot.jpg`)
-   **Dimensions**: 1200 x 900 pixels (4:3 ratio)
-   **Location**: Root directory of the theme
-   **Format**: PNG or JPG
-   **File Size**: Under 1MB recommended

### What to Include in Screenshot

Capture the homepage showing:

1. **Header section** with:

    - Amorf's logo and branding
    - Navigation menu
    - Contact button

2. **Hero section** with:

    - Featured post card (large)
    - Recent posts sidebar (right)

3. **Category sidebar** (left side)

4. **Blog grid** (at least 2-3 cards visible)

### How to Create Screenshot

#### Option 1: Browser Screenshot

1. Set browser to 1200px width
2. Navigate to your homepage
3. Take a full-page screenshot
4. Crop to 1200x900px showing the best parts
5. Save as `screenshot.png`

#### Option 2: Design Tool

1. Use Figma, Photoshop, or Sketch
2. Create a 1200x900px canvas
3. Add representative theme elements
4. Export as PNG
5. Save as `screenshot.png`

#### Option 3: Online Screenshot Tools

-   Use services like:
    -   Screely (screely.com)
    -   Screenshot.guru
    -   Browserframe (browserframe.com)

### Important Notes

-   The screenshot appears in **Appearance > Themes** in WordPress admin
-   It's the first impression users see
-   Must be added manually (not included in this package)
-   Should showcase the theme's best features

### Fallback

If you don't create a screenshot, WordPress will show a placeholder image with the theme name.
